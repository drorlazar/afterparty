    How it works

    Four habits, one tidy disk

    Afterparty teaches the party to clean up after itself. Open a part to watch it.

    Part 1 One bin for every agent

    Your agents put their scraps, like render frames, downloads and test output, in one .scratch folder per project, so throwaway files never mix with your work.

    Touches

    • Run folders inside .scratch that have sat idle for 3 days or more

    Never touches

    • Anything outside .scratch
    • A run that is still open, was written to recently or holds git-tracked files
    Details for the curious
    • The installer adds a short hygiene rule to ~/.claude/CLAUDE.md and ~/.codex/AGENTS.md, only if you agree.
    • Idle run folders are offered at your next clean, for example my-app/.scratch/render-2/. They are cleared automatically only with autopilot on.
    • The idle threshold is scratch_days in ~/.config/afterparty/config.json (default 3).
    Part 2 Clean up before you leave

    When a task is done, type /tidy. It lists what the task left behind and asks before it removes anything.

    Touches

    • Scraps, frames, caches and dependency folders in the folder you name, inside your project folders
    • Only the items you say yes to

    Never touches

    • Git-tracked files, final renders and sources
    • Anything outside that folder
    Details for the curious
    • Under the hood it runs afterparty tidy video-project/. Keep or drop single items with --only or --skip and the ids from the report.
    • Render frames go to the Trash, including the latest version. afterparty undo puts them back.
    • Example from a render job: /tidy? 4.8 GB.
    Part 3 The Sunday sweep

    Once a week, Afterparty checks your project folders and sends one notification with what it found. It cleans only when you say yes.

    Touches

    • Nothing by default: it reports and notifies
    • With autopilot on: caches, dependency folders, scraps and old render versions

    Never touches

    • Worktrees and personal files, even with autopilot on
    • Your protected folders
    Details for the curious
    • A weekly job runs afterparty report --notify, for example "Found 12 GB. Run /afterparty to clean."
    • A daily check warns when free space drops below low_space_gb (default 50).
    • afterparty autopilot on asks you to confirm, then lets the weekly job clean. Old render versions go to the Trash with undo. afterparty autopilot off goes back to reports.
    Part 4 The map of everything

    Open the map to see every folder on your disk as blocks sized by the space they use, with a plain reason for what each one is.

    Touches

    • Only items you pick, after you review and confirm the list
    • Anything you override goes to the Trash, never straight to deletion

    Never touches

    • System areas, app internals and symlinks
    • Anything on your keep list, or marked protected, even if you override
    Details for the curious
    • Open it with afterparty map. The scan runs entirely on your Mac.
    • Items outside your project folders can only go to the Trash.
    • Sizes are the space a folder really uses: hard links and APFS clones are counted once, so it can show ranges like "frees at least 2 GB (up to 3 GB)".
    • Without Full Disk Access, protected folders are skipped and reported, never guessed at.

    Sizes and paths on this page are examples.

    Safe by design

    Nothing goes without a rule or your OK

    Your work is never offered

    Git-tracked files, final renders and sources, your protected folders.

    Asks first

    Reports by default; nothing is cleaned until you say yes or turn autopilot on.

    Undo for the rest

    Caches, dependency folders and your agents' .scratch scraps are cleared for good; big downloads (models, package stores) are offered one by one and download again; idle worktrees go only when every commit is on your remote; everything else goes to the Trash with undo.

    Install

    Paste one line into Claude Code

    Claude Code

    Install Afterparty from https://github.com/drorlazar/afterparty — read INSTALL.md and follow it.

    Requires macOS 13 or later, git and Claude Code or Codex. The optional map app also needs Swift from the Xcode Command Line Tools.

    Uninstall any time with afterparty uninstall. It removes only what the installer created; add --purge to remove your settings and logs too.

    What Claude will do

    1. Check your Mac: macOS 13 or later, git and a working Python 3.9 or newer.
    2. Download Afterparty to ~/.afterparty.
    3. Show you every file, link, job and text block it would create, before creating any.
    4. Ask which project folders to watch, which to protect, whether to add the .scratch rule, and whether to turn on the optional agent (default no).
    5. Install with your answers.
    6. Offer to build the map app, if Swift is available.
    7. Explain Full Disk Access and open that settings pane for you.
    8. Run a first report and sum it up in plain words.

    It never runs a command that deletes your files.

    FAQ

    Questions, answered

    Does anything leave my Mac?

    Scanning and cleaning are entirely local. The optional "Ask Claude about this folder" feature is off by default; when you use it, it sends that folder's paths, file names and sizes (never file contents unless you allow the agent to read files) to Claude through your own Claude Code account, and shows you exactly what will be sent first.

    What gets deleted for good?

    Caches and dependency folders that rebuild themselves, and .scratch runs your agents marked as throwaway. Idle worktrees are removed only when every commit is on your remote. Downloaded models and full package caches are offered one by one, and re-download when needed.

    Why Full Disk Access?

    Without it, protected folders are skipped and reported, never guessed at.

    Does it work with Codex?

    Yes, skills and the hygiene rule install for Codex too.

    Can I undo a cleanup?

    Yes, for everything that went to the Trash: run afterparty undo, or name a run to undo just that one. It works for cleanups from the command line and from the map app. Things removed for good rebuild or download again instead.

    How do I uninstall?

    afterparty uninstall.
