# Font licences

All three fonts are vendored here so the page loads nothing from a CDN at runtime.
Each is licensed under the SIL Open Font License, Version 1.1; the full licence text
for each is in the matching `OFL-*.txt` file next to it.

| File | Font | Source | Licence |
|---|---|---|---|
| `Sora-var-latin.woff2` | Sora (variable weight, Latin subset) | The Sora Project Authors, https://github.com/sora-xor/sora-font (packaged as `@fontsource-variable/sora` 5.3.0) | OFL 1.1, `OFL-Sora.txt` |
| `Inter-var.woff2` | Inter (variable weight) | The Inter Project Authors, https://github.com/rsms/inter | OFL 1.1, `OFL-Inter.txt` |
| `JetBrainsMono-var.woff2` | JetBrains Mono (variable weight) | The JetBrains Mono Project Authors, https://github.com/JetBrains/JetBrainsMono | OFL 1.1, `OFL-JetBrainsMono.txt` |

Use: Sora for display and labels, Inter for body text and captions, JetBrains Mono only for real commands.
